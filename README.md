# Chatter Landing Page

A pixel-perfect, responsive HTML5 & CSS3 implementation of the Chatter landing page design from Figma.

## 🚀 Live Demo & Hosting
Hosted on GitHub Pages / Vercel.

## 📁 Project Structure
- `index.html` — Semantic HTML5 structure
- `styles.css` — Responsive CSS3 styling with mobile breakpoints
- `script.js` — Mobile navigation toggle & keyboard accessibility
- `assets/`
  - `chatter-logo.svg` — Official Chatter brand logo
  - `analytics-icon.svg` — Feature card icon for Analytics
  - `social-icon.svg` — Feature card icon for Social interactions
  - `content-icon.svg` — Feature card icon for Content creation
  - `testimonial-avatar.png` — High-res avatar for Adebobola Muhydeen
  - `avatar-1.png`, `avatar-2.png`, `avatar-3.png` — Community avatar cluster

## 💻 Run Locally
Open `index.html` directly in your browser, or start a local HTTP server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
